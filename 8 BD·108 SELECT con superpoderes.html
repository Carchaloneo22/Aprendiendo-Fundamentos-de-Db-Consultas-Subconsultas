01

WHERE: el filtro básico

⏱ 20 min práctica
WHERE es la cláusula que filtra las filas de una consulta. Solo devuelve las filas que cumplen la condición que especifiques. Sin WHERE, SELECT devuelve todas las filas de la tabla.

Los operadores de comparación

OperadorSignificadoEjemplo
=Igual aWHERE precio = 2500
<>Diferente deWHERE precio <> 2500
<Menor queWHERE precio < 2500
>Mayor queWHERE precio > 2500
<=Menor o igualWHERE precio <= 2500
>=Mayor o igualWHERE precio >= 2500

Ejemplos con la tabla productos

Ejemplo 1: igualdad 
-- Todos los productos que cuestan exactamente 2500
SELECT nombre, precio FROM productos WHERE precio = 2500;

Resultado: solo "Empanada" (2500).

Ejemplo 2: mayor que 
-- Todos los productos que cuestan más de 3000
SELECT nombre, precio FROM productos WHERE precio > 3000;

Resultado: Gaseosa (3800), Jugo de mango (3000) no porque es exactamente 3000, Papas fritas (4000), Chocolate (3500).

Ejemplo 3: diferente de 
-- Todos los productos que NO están en la categoría 1 (Bebidas)
SELECT nombre, categoria_id FROM productos WHERE categoria_id <> 1;

Resultado: Empanada, Arepas, Papas fritas, Chitos, Chocolate, Bon Bon Bum.

Ejemplos con texto

Ejemplo 4: texto exacto 
-- Buscar un producto por su nombre exacto
SELECT * FROM productos WHERE nombre = 'Empanada';
Ejemplo 5: comparación de texto 
-- Los nombres que vienen alfabéticamente después de 'J'
SELECT nombre FROM productos WHERE nombre > 'J';

Resultado: Jugo de mango, Papas fritas, Chitos... (todos los que empiezan con letras después de J).

Ejemplos con BIT (activo)

Ejemplo 6: productos activos 
-- Solo los productos que están activos (activo = 1)
SELECT nombre, precio FROM productos WHERE activo = 1;
Ejemplo 7: productos inactivos 
-- Solo los productos que NO están activos (activo = 0)
SELECT nombre, precio FROM productos WHERE activo = 0;

Mini reto ⚡

Escribe la consulta que devuelva solo los productos que cuestan menos de 2000.

Ver solución 
SELECT nombre, precio FROM productos WHERE precio < 2000;

Resultado: Café (1800), Agua en botella (1500), Bon Bon Bum (800).

02

AND, OR, NOT: combinar condiciones

⏱ 20 min práctica
OperadorQué haceEjemplo
ANDAmbas condiciones deben ser verdaderas.WHERE precio > 2000 AND activo = 1
ORAl menos una condición debe ser verdadera.WHERE categoria_id = 1 OR categoria_id = 2
NOTNiega la condición.WHERE NOT activo = 1

Ejemplos con AND

Ejemplo 1: dos condiciones obligatorias 
-- Productos que cuestan más de 2000 Y están activos
SELECT nombre, precio, activo FROM productos
WHERE precio > 2000 AND activo = 1;
Ejemplo 2: tres condiciones con AND 
-- Productos de la categoría 1, que cuestan más de 2000 y están activos
SELECT nombre, precio FROM productos
WHERE categoria_id = 1 AND precio > 2000 AND activo = 1;

Resultado: Gaseosa (3800) y Jugo de mango (3000). Café no porque cuesta 1800. Agua no porque cuesta 1500.

Ejemplos con OR

Ejemplo 3: alternativas 
-- Productos de la categoría 1 (Bebidas) O de la categoría 4 (Dulces)
SELECT nombre, categoria_id FROM productos
WHERE categoria_id = 1 OR categoria_id = 4;
Ejemplo 4: OR con rangos 
-- Productos que cuestan menos de 1000 O más de 3500
SELECT nombre, precio FROM productos
WHERE precio < 1000 OR precio > 3500;

Resultado: Bon Bon Bum (800), Gaseosa (3800), Papas fritas (4000).

Ejemplos combinando AND y OR

Ejemplo 5: paréntesis para controlar el orden 
-- Productos activos que son de la categoría 1 o de la categoría 2
SELECT nombre, categoria_id FROM productos
WHERE activo = 1 AND (categoria_id = 1 OR categoria_id = 2);

Los paréntesis son importantes: sin ellos, el AND se evalúa antes que el OR y el resultado puede ser diferente al que esperas.

Ejemplos con NOT

Ejemplo 6: negar una condición 
-- Productos que NO están activos
SELECT nombre FROM productos WHERE NOT activo = 1;
Ejemplo 7: NOT con OR 
-- Productos que NO son de la categoría 1 ni de la categoría 2
SELECT nombre, categoria_id FROM productos
WHERE NOT (categoria_id = 1 OR categoria_id = 2);

Mini reto ⚡

Escribe la consulta que devuelva los productos que son de la categoría 3 (Snacks) y cuestan más de 3000.

Ver solución 
SELECT nombre, precio FROM productos
WHERE categoria_id = 3 AND precio > 3000;

Resultado: solo Papas fritas (4000). Chitos cuesta 2200, así que no cumple.

03

LIKE, IN, BETWEEN, IS NULL: filtros avanzados

⏱ 25 min práctica

LIKE: buscar patrones en texto

PatrónQué buscaEjemplo
LIKE 'A%'Empieza con A.WHERE nombre LIKE 'A%'
LIKE '%a'Termina con a.WHERE nombre LIKE '%a'
LIKE '%an%'Contiene "an" en cualquier parte.WHERE nombre LIKE '%an%'
LIKE '_a%'Segunda letra es "a" (el guion bajo es un solo carácter).WHERE nombre LIKE '_a%'
Ejemplo 1: productos que empiezan con "A" 
-- Todos los productos cuyo nombre empieza con A
SELECT nombre FROM productos WHERE nombre LIKE 'A%';

Resultado: Arepas, Agua en botella.

Ejemplo 2: productos que contienen "de" 
-- Todos los productos cuyo nombre contiene "de"
SELECT nombre FROM productos WHERE nombre LIKE '%de%';

Resultado: Jugo de mango, Agua en botella, Papas fritas (contiene "de" en "Papas de fritas"... espera, no. En realidad: Jugo de mango. Revisa tus datos).

Ejemplo 3: productos que terminan con "a" 
-- Todos los productos cuyo nombre termina con a
SELECT nombre FROM productos WHERE nombre LIKE '%a';

Resultado: Gaseosa 400 ml, Empanada, Arepas, Papas fritas, Chitos no... depende de tus datos.

IN: filtrar por una lista de valores

Ejemplo 4: productos en categorías específicas 
-- Productos de las categorías 1, 3 o 4 (equivalente a OR)
SELECT nombre, categoria_id FROM productos
WHERE categoria_id IN (1, 3, 4);

Esto es equivalente a WHERE categoria_id = 1 OR categoria_id = 3 OR categoria_id = 4, pero más corto y legible.

Ejemplo 5: IN con texto 
-- Buscar clientes por nombre
SELECT * FROM clientes
WHERE nombre IN ('Valentina Ruiz', 'Carlos Peña');

BETWEEN: filtrar por un rango

Ejemplo 6: productos en un rango de precios 
-- Productos que cuestan entre 2000 y 3500 (inclusive)
SELECT nombre, precio FROM productos
WHERE precio BETWEEN 2000 AND 3500;

BETWEEN incluye ambos extremos. Es equivalente a WHERE precio >= 2000 AND precio <= 3500.

Ejemplo 7: BETWEEN con cantidades 
-- Productos con cantidad entre 20 y 50
SELECT nombre, cantidad FROM productos
WHERE cantidad BETWEEN 20 AND 50;

IS NULL: buscar valores vacíos

Ejemplo 8: clientes sin teléfono 
-- Clientes que no tienen teléfono registrado
SELECT nombre, telefono FROM clientes
WHERE telefono IS NULL;

Resultado: Luis Mora (su teléfono es NULL).

Ejemplo 9: clientes con teléfono 
-- Clientes que SÍ tienen teléfono registrado
SELECT nombre, telefono FROM clientes
WHERE telefono IS NOT NULL;
⚠️ Cuidado con NULLNo puedes usar = NULL ni <> NULL. NULL significa "desconocido", y no se puede comparar con operadores normales. Siempre usa IS NULL o IS NOT NULL.

Mini reto ⚡

Escribe una consulta que devuelva los productos cuyo nombre contiene la letra "o" y cuestan entre 1500 y 3000.

Ver solución 
SELECT nombre, precio FROM productos
WHERE nombre LIKE '%o%' AND precio BETWEEN 1500 AND 3000;

Resultado: Jugo de mango (3000), Agua en botella (1500), Chocolate (3500) no porque supera 3000.

04

ORDER BY y TOP: ordenar y limitar

⏱ 15 min práctica

ORDER BY: ordenar los resultados

Ejemplo 1: ordenar ascendente (por defecto) 
-- Productos ordenados por precio de menor a mayor
SELECT nombre, precio FROM productos ORDER BY precio;
Ejemplo 2: ordenar descendente 
-- Productos ordenados por precio de mayor a menor
SELECT nombre, precio FROM productos ORDER BY precio DESC;
Ejemplo 3: ordenar por varias columnas 
-- Ordenar por categoría y luego por precio dentro de cada categoría
SELECT nombre, categoria_id, precio FROM productos
ORDER BY categoria_id, precio DESC;

TOP: limitar la cantidad de filas

Ejemplo 4: los 3 productos más caros 
-- Los 3 productos más caros
SELECT TOP 3 nombre, precio FROM productos ORDER BY precio DESC;
Ejemplo 5: los 5 productos más baratos 
-- Los 5 productos más baratos
SELECT TOP 5 nombre, precio FROM productos ORDER BY precio;
Ejemplo 6: TOP con porcentaje 
-- El 20% de los productos más caros
SELECT TOP 20 PERCENT nombre, precio FROM productos ORDER BY precio DESC;
💡 El orden importaTOP sin ORDER BY devuelve las primeras filas que SQL Server encuentre, que pueden no ser las que esperas. Siempre combina TOP con ORDER BY para obtener resultados predecibles.

Mini reto ⚡

Escribe la consulta que devuelva los 2 productos con mayor cantidad en inventario.

Ver solución 
SELECT TOP 2 nombre, cantidad FROM productos ORDER BY cantidad DESC;

Resultado: Agua en botella (60), Bon Bon Bum (50).

05

Funciones de agregado y DISTINCT

⏱ 25 min práctica

Las funciones de agregado resumen un conjunto de filas en un solo valor. Son la base de los reportes y análisis.

FunciónQué haceEjemplo
COUNT(*)Cuenta las filas.SELECT COUNT(*) FROM productos;
SUM(col)Suma los valores de una columna.SELECT SUM(precio) FROM productos;
AVG(col)Calcula el promedio.SELECT AVG(precio) FROM productos;
MIN(col)Devuelve el valor mínimo.SELECT MIN(precio) FROM productos;
MAX(col)Devuelve el valor máximo.SELECT MAX(precio) FROM productos;

Ejemplos básicos

Ejemplo 1: contar productos 
-- ¿Cuántos productos hay en total?
SELECT COUNT(*) FROM productos;

Resultado: 10.

Ejemplo 2: contar productos activos 
-- ¿Cuántos productos están activos?
SELECT COUNT(*) FROM productos WHERE activo = 1;

Resultado: 9 (todos menos Café).

Ejemplo 3: suma total del inventario 
-- ¿Cuál es el valor total del inventario (precio × cantidad)?
SELECT SUM(precio * cantidad) FROM productos;
Ejemplo 4: precio promedio 
-- ¿Cuál es el precio promedio de los productos?
SELECT AVG(precio) FROM productos;
Ejemplo 5: producto más caro y más barato 
-- El precio más alto y el más bajo
SELECT MAX(precio) AS mas_caro, MIN(precio) AS mas_barato FROM productos;

Resultado: mas_caro = 4000, mas_barato = 800.

DISTINCT: eliminar duplicados

Ejemplo 6: categorías únicas 
-- ¿Qué categorías distintas tienen los productos?
SELECT DISTINCT categoria_id FROM productos;

Resultado: 1, 2, 3, 4 (cada categoría aparece una sola vez, aunque haya varios productos en ella).

Ejemplo 7: contar categorías distintas 
-- ¿En cuántas categorías diferentes hay productos?
SELECT COUNT(DISTINCT categoria_id) FROM productos;

Resultado: 4.

Renombrar columnas con AS

Ejemplo 8: alias para resultados más claros 
-- Usar alias para que el resultado sea más legible
SELECT COUNT(*) AS total_productos,
       AVG(precio) AS precio_promedio,
       MAX(precio) AS precio_maximo
FROM productos;
06

GROUP BY y HAVING: agrupar y filtrar grupos

⏱ 20 min práctica
GROUP BY agrupa las filas por una o más columnas y calcula las funciones de agregado para cada grupo. HAVING filtra los grupos después de calcular los agregados (es el WHERE de los grupos).

Ejemplos con GROUP BY

Ejemplo 1: contar productos por categoría 
-- ¿Cuántos productos hay en cada categoría?
SELECT categoria_id, COUNT(*) AS cantidad
FROM productos
GROUP BY categoria_id;

Resultado: categoría 1 tiene 4 productos, categoría 2 tiene 2, categoría 3 tiene 2, categoría 4 tiene 2.

Ejemplo 2: precio promedio por categoría 
-- ¿Cuál es el precio promedio en cada categoría?
SELECT categoria_id, AVG(precio) AS precio_promedio
FROM productos
GROUP BY categoria_id;
Ejemplo 3: valor total del inventario por categoría 
-- ¿Cuánto vale el inventario de cada categoría?
SELECT categoria_id, SUM(precio * cantidad) AS valor_inventario
FROM productos
GROUP BY categoria_id;

Ejemplos con HAVING

Ejemplo 4: categorías con más de 2 productos 
-- ¿Qué categorías tienen más de 2 productos?
SELECT categoria_id, COUNT(*) AS cantidad
FROM productos
GROUP BY categoria_id
HAVING COUNT(*) > 2;

Resultado: solo la categoría 1 (Bebidas) tiene 4 productos.

Ejemplo 5: categorías con precio promedio mayor a 2500 
-- ¿Qué categorías tienen un precio promedio mayor a 2500?
SELECT categoria_id, AVG(precio) AS precio_promedio
FROM productos
GROUP BY categoria_id
HAVING AVG(precio) > 2500;

WHERE vs HAVING

CláusulaCuándo se aplicaQué filtra
WHEREAntes de agrupar.Filas individuales.
HAVINGDespués de agrupar.Grupos completos.
Ejemplo 6: WHERE y HAVING juntos 
-- Solo productos activos, agrupados por categoría,
-- mostrando solo las categorías con más de 1 producto activo
SELECT categoria_id, COUNT(*) AS cantidad
FROM productos
WHERE activo = 1              -- filtra filas individuales
GROUP BY categoria_id
HAVING COUNT(*) > 1;         -- filtra grupos

Mini reto ⚡

Escribe una consulta que muestre la cantidad total de unidades en inventario por cada categoría, pero solo para las categorías que tienen más de 30 unidades en total.

Ver solución 
SELECT categoria_id, SUM(cantidad) AS total_unidades
FROM productos
GROUP BY categoria_id
HAVING SUM(cantidad) > 30;

🏆 Reto integrador: el informe de la tienda

⏱ 20 min · equipos

El gerente de la tienda escolar te pidió un informe. Escribe las siguientes consultas combinando todos los conceptos de esta entrega:

  • a) Los 3 productos más caros que están activos.
  • b) El nombre y precio de los productos de la categoría 1 que cuestan entre 2000 y 3500, ordenados por precio de mayor a menor.
  • c) El número de productos activos e inactivos por categoría.
  • d) Las categorías cuyo valor total de inventario supera los 100000.
  • e) El precio promedio de los productos activos vs. los inactivos.
  • f) Los nombres de los productos que empiezan con vocal (A, E, I, O, U).
✏️ Espacio de borrador del equipo.
💡 Pista

Para el punto (f), puedes usar WHERE nombre LIKE 'A%' OR nombre LIKE 'E%' OR ... o más elegante: WHERE nombre LIKE '[AEIOU]%'.

🔍 Solución completa 
-- a) Los 3 productos más caros que están activos
SELECT TOP 3 nombre, precio FROM productos
WHERE activo = 1 ORDER BY precio DESC;

-- b) Productos de la categoría 1 entre 2000 y 3500, ordenados
SELECT nombre, precio FROM productos
WHERE categoria_id = 1 AND precio BETWEEN 2000 AND 3500
ORDER BY precio DESC;

-- c) Número de productos activos e inactivos por categoría
SELECT categoria_id, activo, COUNT(*) AS cantidad
FROM productos GROUP BY categoria_id, activo ORDER BY categoria_id;

-- d) Categorías con valor de inventario superior a 100000
SELECT categoria_id, SUM(precio * cantidad) AS valor_inventario
FROM productos GROUP BY categoria_id
HAVING SUM(precio * cantidad) > 100000;

-- e) Precio promedio de activos vs inactivos
SELECT activo, AVG(precio) AS precio_promedio
FROM productos GROUP BY activo;

-- f) Productos que empiezan con vocal
SELECT nombre FROM productos
WHERE nombre LIKE '[AEIOU]%';

Este reto combina WHERE, BETWEEN, ORDER BY, TOP, COUNT, SUM, AVG, GROUP BY, HAVING y LIKE. Si tu equipo lo resuelve completo, dominan SELECT. ¡Felicitaciones! 🎉

Mini glosario de esta entrega

Consulta rápida
WHERE
Cláusula que filtra las filas de una consulta según una condición.
AND / OR / NOT
Operadores lógicos para combinar condiciones en WHERE.
LIKE
Operador para buscar patrones en texto. Usa % (cualquier cantidad de caracteres) y _ (un solo carácter).
IN
Operador para filtrar por una lista de valores específicos.
BETWEEN
Operador para filtrar por un rango de valores (inclusive).

Operadores para buscar valores vacíos o no vacíos. No se puede usar = NULL.
ORDER BY
Cláusula para ordenar los resultados por una o más columnas.
TOP
Cláusula para limitar la cantidad de filas devueltas.
DISTINCT
Cláusula para eliminar filas duplicadas del resultado.
COUNT, SUM, AVG, MIN, MAX
Funciones de agregado que resumen un conjunto de filas en un solo valor.
GROUP BY
Cláusula que agrupa filas por una o más columnas para calcular agregados por grupo.
HAVING
Cláusula que filtra los grupos después de calcular los agregados. Es el WHERE de los grupos.
